# Manuscript boundary

The current paper is the EAAI manuscript **A Reproducible Model-Level Verification and Validation Protocol for Predictive AI in High-Impact Educational Assessment: Evidence from PISA 2022**.

The public repository uses `docs/v5_eaai/` plus `reports/tables/v5_*` as the authoritative active claim/evidence layer. The exact 2026-08-25 manuscript/supplement LaTeX package is distributed as a versioned release artifact so that Editorial Manager staging files are not mixed into the scientific source tree.

The earlier `tlt_manuscript.tex`, `supplementary_tlt.tex`, and legacy manuscript-table source represented a previous journal route and old result set (for example AUC 0.903 and RMSE 54.10). Those sources are removed from the active tree but remain recoverable from Git history. They must not be treated as the current EAAI manuscript.

Author-identifying submission artifacts (title page, cover letter, upload checklists) are intentionally excluded from this public research-companion directory.
