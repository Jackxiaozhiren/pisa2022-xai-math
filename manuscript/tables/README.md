# Legacy manuscript tables

The standalone `.tex` tables previously stored in this directory belonged to the superseded TLT manuscript route and legacy result set. They are removed from the active tree for the EAAI release to prevent accidental reuse, while remaining recoverable from Git history.

For the current EAAI manuscript, use `reports/tables/v5_*` and `docs/v5_eaai/EAAI_v5_07_active_result_register.md` as the controlling scientific evidence. The exact 2026-08-25 EAAI LaTeX source package is distributed with the versioned release.
