# Route A Scientific Artifacts

This directory contains public scientific methodology, validity-audit, protocol,
result-register, and validation records for the PISA 2022 model-level
verification study.

The current route uses ten plausible values, 80 Fay--BRR replicate weights,
population/SENWT sensitivity, a matched additive EBM, and a whole-school
institution cold-start stress test. PISA raw files, row-level predictions,
fitted models, author/submission materials, simulated editorial reviews, and
acceptance-forecast documents are not part of the public research package.

The primary active values are recorded in `EAAI_v5_07_active_result_register.md`;
the unseen-school secondary validation is recorded in
`EAAI_v5_12_institution_cold_start_results_and_promotion.md`.

Documents in this directory should support a scientific claim, method,
estimand, validation decision, or reproducibility step. Internal submission
management belongs outside the public companion repository.
